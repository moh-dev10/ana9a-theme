# dz-ecom-starter 🚀

A high-performance, developer-friendly WordPress theme blueprint optimized for the Algerian e-commerce market.

## 🛠 Tech Stack
* **WordPress**: The reliable CMS core.
* **Tailwind CSS v4**: CSS-first configuration for modern styling.
* **Alpine.js**: Lightweight JavaScript framework for reactive UI components.
* **PostCSS**: For advanced CSS processing.
* **Git**: Version control for professional development.

## 🚀 Key Features
* **Reactive Components**: Built-in support for Alpine.js to handle interactive UI elements (e.g., dropdowns, modals, tabs) without heavy JS libraries.
* **Performance Focused**: Minimalist architecture to achieve high Google Lighthouse scores.
* **Ready for DZ-Market**: Pre-configured structure for WooCommerce customization.
* **Developer Experience (DX)**: Optimized workflow with Tailwind's Just-In-Time (JIT) compilation and automatic purging.
