# ANA9A - Luxury E-commerce Theme

A high-end, minimalist WordPress theme built for the Algerian fashion market.

## Tech Stack
- **CMS:** WordPress
- **E-commerce:** WooCommerce
- **Styling:** Tailwind CSS v4 (CSS-first configuration)
- **Architecture:** Modular PHP (Template Parts & Includes)

## How to use
1. Clone this repo into `wp-content/themes/`
2. Run `npm install`
3. Start Tailwind watcher: `npx tailwindcss -i ./input.css -o ./style.css --watch`
